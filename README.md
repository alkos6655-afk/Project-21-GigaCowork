# AI-агент распределения заказов (ФУЛ) между логистами — GigaCowork

Тестовое задание на стажировку Сбер × Школа 21.

Агент принимает три выгрузки Excel (ФУЛ из 1С, реестр Cloud, сотрудники из 1С), определяет новые ФУЛ и повторные отправки, выбирает группу и логиста по правилам заказчика и выдаёт готовый Excel: новые строки Cloud по форме реестра, повторы, возможные пропуски, «Требует внимания» и журнал решений с обоснованием. Решения принимает детерминированный Python-скрипт, модель только запускает его и пересказывает результат.

## Что в репозитории

| Файл | Что внутри |
|---|---|
| `Отчёт_агент_распределения_ФУЛ.pdf` | Вопросы заказчику, алгоритм, допущения, тестовые данные, метрики, мотивация |
| `agent_package.zip` | Навык в формате GigaCowork (SKILL.md, scripts/, references/), системный промпт, инструкция по установке |

| Метрика | Порог | Результат |
|---|---|---|
| Совпадение с эталоном по всем полям | ≥ 95% | 100% (27 из 27 ФУЛ) |
| Форма Cloud: 12 колонок в порядке реестра | 100% | 100% |
| Выдуманные значения на ловушках | 0 | 0 |
| Воспроизводимость (3 прогона) | одинаково | побайтно одинаковый результат |
| Время на пачку | до 1 мин | ~0,2 с |
